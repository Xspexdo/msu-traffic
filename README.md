# 🚦 MSU Traffic - ระบบรายงานและแจ้งเตือนด่านรอบ ม.มหาสารคาม

เว็บแอปพลิเคชันสำหรับชาว มหาวิทยาลัยมหาสารคาม (มมส) เพื่อรายงานและตรวจสอบจุดตั้งด่านตรวจ (หมวกกันน็อก, แอลกอฮอล์, ควันดำ, ตรวจค้น) สภาพการจราจร และอุบัติเหตุแบบ Real-time รองรับทั้ง **Mobile (สมาร์ทโฟน)**, **iPad / Tablet**, และ **PC Desktop**

---

## 🌟 ฟีเจอร์เด่น (Features)

1. **🛡️ ระบบความปลอดภัย ป้องกันการยิงสแปม (Anti-DDoS / Rate Limiter)**:
   - ป้องกันการส่งคำขอเกิน **5 ครั้ง / วินาที** จาก IP เดียวกัน
   - หากตรวจพบการยิงคำขอเกินกำหนด ระบบจะ **แบนชั่วคราวเป็นเวลา 5 นาที (300 วินาที)** ทันที
   - มีหน้าต่างนับเวลาถอยหลัง (Countdown Timer) แสดงสถานะการโดนระงับแบบ Real-time

2. **🔓 สิทธิ์การใช้งาน**:
   - **ทุกคนสามารถเข้าอ่าน/ดูแผนที่/ดูฟีดด่านได้อิสระ** โดยไม่ต้อง Login
   - **หากต้องการโพสต์รายงานด่านใหม่ หรือกดโหวตยืนยันสถานะด่าน** ต้องทำการเข้าสู่ระบบด้วย Google (หรือโหมดทดสอบ Demo Student)

3. **🗺️ แผนที่พิกัด มมส (MSU Interactive Map)**:
   - สลับมุมมองระหว่าง **มอใหม่ (ขามเรียง / ท่าขอนยาง)** และ **มอเก่า (ในเมือง)** ได้ในคลิกเดียว
   - หมุดด่าน Real-time พร้อมวงแหวน Pulse Animation และสีแยกระดับความรุนแรง
   - ปุ่มระบุตำแหน่ง GPS ของผู้ใช้งานปัจจุบัน

4. **📍 จุดยอดนิยมรอบ มมส (Preset Hotspots)**:
   - หน้าป้าย มมส (มอใหม่ ขามเรียง)
   - ประตู 1 มมส ใหม่ / หอพัก
   - วงเวียนป่าไม้ / ตลาดน้อย
   - สามแยกไฟแดงท่าขอนยาง
   - สะพานข้ามคลองท่าขอนยาง (สะพานดำ)
   - ถนนหลังมอ / โค้งเซเว่นคลองถม
   - สี่แยกบ้านขามเรียง
   - ถนนเลี่ยงเมือง มมส - แยกตักสิลา
   - หน้าป้าย มอเก่า (ในเมือง)
   - สี่แยกหอนาฬิกา / เสริมไทยพลาซ่า
   - หรือสามารถ **ปักหมุดเองบนแผนที่ หรือ พิมพ์ชื่อสถานที่เองได้อย่างอิสระ**

5. **👍 ระบบโหวตยืนยันโดยชุมชน (Community Voting)**:
   - กดโหวต **"👍 ยังมีอยู่"** หรือ **"🚀 ยกด่านแล้ว"**
   - เมื่อมีผู้รายงานยกด่านหลายคน ระบบจะเปลี่ยนสถานะด่านเป็นสีเขียว/ยกด่านแล้วอัตโนมัติ

6. **🔔 ระบบแจ้งเตือนเสียง (Audio Alerts)**:
   - มีเสียง Chime สังเคราะห์แจ้งเตือนทันทีเมื่อมีผู้รายงานด่านใหม่เข้ามา

7. **📱 รองรับ Responsive 100%**:
   - **Mobile**: มีแถบ Bottom Navigation ด้านล่าง + Floating Action Button (FAB) รายงานด่านสะดวก
   - **iPad / Tablet**: มุมมอง Split-Screen 2 คอลัมน์
   - **PC Desktop**: แดชบอร์ดกว้างพร้อม Multi-panel widgets

## 🚀 วิธีการติดตั้งและรันระบบ (How to Run)

```bash
# 1. ติดตั้ง Dependencies (ทำครั้งแรก)
npm install

# 2. เริ่มต้นรันเซิร์ฟเวอร์
npm start

# หรือรันในโหมดพัฒนา (Auto Reload)
npm run dev
```

เปิด Browser แล้วไปที่: **`http://localhost:3000`**
